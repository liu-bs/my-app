# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

注册作者。任何人可注册成为作者,发布和管理自己的文章、评论、收藏。
游客可阅读已发布文章,但写作、评论、收藏、资料编辑需登录。

## Product Purpose

一个多作者中文技术写作平台。让工程师记录和分享值得反复读的深度思考,
以极致极简的黑白灰质感和工程化阅读体验为差异化。

成功 = 作者愿意长期沉淀内容,读者获得高质量工程笔记。

## Positioning

不同于通用博客平台,这里强调:

- 工程质感:Markdown 渲染、代码高亮、目录、阅读体验是核心而非附加
- 极简美学:克制的设计语言(中性灰阶 + 四色点缀),内容优先
- 多作者独立:每个作者管理自己的文章和统计,平台是共写作空间而非个人站

## Operating Context

- 纯中文界面(zh-CN),暂无 i18n 计划
- 明暗双主题 + 字号调节,读者可自定义阅读环境
- SSR 首屏(首页/列表/详情为 Server Components),React Query 客户端交互
- 文章支持封面、分类、标签、置顶、草稿状态
- 鉴权基于 HttpOnly Cookie JWT,同源代理无跨域

## Capabilities and Constraints

已实现:

- 文章 CRUD(草稿/置顶/封面 URL/分类/标签)
- 列表分页、搜索、分类与标签筛选
- 文章详情:阅读量、点赞、收藏、评论、目录、代码高亮
- 用户注册/登录/登出/改密/改资料
- 主题(light/dark/system)+ 字号
- 个人中心:我的文章 + 收藏 Tab
- 站点配置:blogName / author
- sitemap / robots / OG

约束:

- 封面图必须为 http(s) URL,无图片上传
- 无管理后台、无内容审核、无作者分级
- 后端当前为 JSON 文件存储(生产用,计划迁移真实数据库)
- 品牌名与作者署名为占位值,待定

## Product Principles

1. 内容优先:设计为阅读服务,装饰为内容让路
2. 工程克制:少即是多,每个视觉元素要有理由
3. 多作者共写作:平台气质中性,作者个性通过内容体现
4. 阅读体验即产品:排版、对比度、状态完整度是核心功能
5. 诚实:不堆砌占位内容,空状态和错误状态也要精心设计

## Accessibility & Inclusion

- WCAG AA 对比度(正文 ≥4.5:1,大字 ≥3:1)
- 全键盘可达,焦点可见
- 明暗主题对比度独立校准
- 移动端响应式,触摸友好
